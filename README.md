# alexbarbu portfolio

Plain HTML/CSS/JS. No framework, no build step for the page itself. A GitHub Action pulls repo data at build time and deploys to GitHub Pages.

```
index.html               page shell
assets/                  style.css, app.js, images, CV
content/profile.js       everything written about you: edit this
content/repo-config.json which repos show, private allowlist, description overrides
data/github.js           GENERATED by the Action (seeded with public data from 25 Sep 2026)
scripts/fetch-github.mjs the build-time fetch
.github/workflows/deploy.yml
```

## Preview locally

Open `index.html` in a browser. It works from `file://` because data loads as `<script>` tags, not `fetch`.

## Deploy (GitHub Pages)

1. Push this folder to a new repo, e.g. `AlexBrb278/AlexBrb278.github.io` (that name serves at `https://alexbrb278.github.io`).
2. Repo **Settings → Pages → Source: GitHub Actions**.
3. Create a fine-grained token: **GitHub Settings → Developer settings → Fine-grained tokens**.
   - Resource owner: you. Repository access: **All repositories** (or pick the private ones you want listed).
   - Permissions: **Metadata: Read-only**. Nothing else.
   - Set an expiry and a calendar reminder to rotate it. When it expires the build falls back to public repos only; it doesn't break.
4. Add it to the portfolio repo: **Settings → Secrets and variables → Actions → New secret**, name `PORTFOLIO_PAT`.
5. **Actions → Build and deploy portfolio → Run workflow.**

It then rebuilds on every push, daily at 04:17 UTC, and on demand.

## Private repos

Nothing private is published unless its exact name is in `private_allowlist` in `content/repo-config.json`. For each one you add, also add an `overrides` entry with a description written for strangers. After each run, the Actions run summary lists exactly what went public.

Private cards show a lock badge and aren't clickable (a link would 404 for visitors).

## Things to know

- GitHub pauses scheduled workflows after 60 days with no commits to the repo. A push or a manual run re-enables it.
- The GitHub heatmap hides itself below `contributions_min_to_show` (150). Private contributions only count if you enable **Profile → Contributions & activity → Include private contributions**.
- Custom domain: add it under Settings → Pages, then a `CNAME` DNS record pointing to `alexbrb278.github.io`.
